# 交互改造 Phase 2 · Simulation 对比 + 灯箱缩放

> 目标：让仿真结果「可比较」，而不只是「可放大」。

## 1. 为什么是「对比」而不是更多动效

Simulation 页原本已有灯箱与 GIF 播放，但一次只能看一张图。仿真研究里真正费时的是**比较两次结果**（不同参数、不同方法、不同时刻）。所以这一阶段加的是：

- 网格 / 对比双视图；
- 两张图并排、**同步缩放平移**；
- 灯箱里能放大细节（滚轮、拖拽、复位）。

## 2. 视图切换

| 项 | 行为 |
|---|---|
| 切换条 | 页面顶部「网格 / 对比」分段按钮，`aria-pressed` 标记当前态；右侧提示随状态变化 |
| URL | 对比模式写入 `?view=compare`，刷新/分享可还原 |
| 网格模式 | 保持原有：点图开灯箱，GIF 可播放 |
| 对比模式 | 点图变为**选择**（不打开灯箱），GIF 播放暂停（避免两个动画同时解码） |

## 3. 选择与并排面板

| 项 | 规格 |
|---|---|
| 可选数量 | 最多 2 张；选中项左上角 28px 圆形序号，图片描边 2px 强调色 |
| 选满 | 自动在网格上方展开「并排对比」面板 |
| 面板内容 | 左右两栏，各用 `data-poster`（800px 静帧）+ 中英图注；不加载 4MB 原图 |
| 取消 | 再点已选项取消；「清除选择」清空并收起面板 |
| 超过 2 张 | 提示「最多选择 2 张，请先取消一张」，不自动替换，避免误操作 |

**为什么用静帧而不是原图/GIF**：对比看的是结构、形态、分布，800px 静帧足够；两个 GIF 同时解码会显著占内存/CPU；原图里最大 4MB，对比时没必要。

## 4. 同步缩放 / 平移

| 项 | 规格 |
|---|---|
| 共享状态 | 一个 `{scale, x, y}` 同时应用到两栏，拖任一栏两栏一起动 |
| 滚轮 | 以指针为锚点，1×–6×，每次 1.12；`preventDefault` 阻止页面滚动 |
| 拖拽 | Pointer Events + `setPointerCapture`；`touch-action:none`，单指可拖 |
| 复位 | 双击，或 `1:1` 按钮 |
| 按钮 | `−` / `1:1` / `+`，44×44 命中区；以舞台中心缩放 |
| 布局 | 容器 ≥700px 左右并排；<700px 上下堆叠，舞台高度 `min(34vh, 280px)` |

## 5. 灯箱缩放

| 项 | 规格 |
|---|---|
| 滚轮 | 以指针为锚点，1×–5×，每次 1.15 |
| 拖拽 | 同上，Pointer Events；`.sim-lightbox__media` 为定位容器 |
| 复位 | 双击、`0` 键、`1:1` 按钮 |
| 键盘 | `+` / `=` 放大，`-` / `_` 缩小，`0` 复位；`Esc` 关闭、`←` `→` 翻页保持原状 |
| 切图 | `render()` 时重置缩放，每张图独立 |
| 可访问性 | 缩放按钮 44×44、`aria-label`；灯箱 `role="dialog"` / 焦点陷阱 / 焦点归还不变 |

## 6. 刻意不做的

- 不做双指缩放（移动端用按钮 + 单指拖拽，避免手势冲突与实现风险）。
- 不做 3D 旋转、不做图片轮播、不做自动播放。
- 不做对比滑杆（before/after slider）——两张图比例/内容不同，滑杆会裁掉一半信息。
- 不引入 canvas / 第三方缩放库，全部用 CSS transform。

## 7. 性能与可访问性

| 项 | 结果 |
|---|---|
| JS | `simulation.js` 13.1 KB → 23.5 KB raw / **6.8 KB gzip**（仍 ≤10 KB 预算） |
| CSS | `simulation.css` 207 → 303 行，+约 3 KB |
| 渲染 | 只写 `transform`，不触发布局；无 canvas、无 rAF 循环 |
| 图片 | 对比面板只用 800px 静帧，首屏不多请求；GIF 在对比模式不加载 |
| 键盘 | 视图切换、选择、缩放、翻页全部可键盘操作；`aria-pressed` / `aria-label` 完整 |
| 减少动效 | 视图切换无动画；灯箱仅有 120ms opacity，reduce 下由 CSS 归零 |

## 8. 验证记录（真实 Chrome + CDP）

| 检查 | 结果 |
|---|---|
| 视图切换 | `data-view` grid→compare，URL `?view=compare`，按钮 `aria-pressed=true` |
| 选择 | 两次点击后 `is-picked=2`、序号 `["1","2"]`、面板展开、两栏 poster 正确 |
| 同步缩放 | `+` 后两栏 transform 完全相同：`translate(-39px,-34.2px) scale(1.2)` |
| 同步拖拽 | 派发 pointer 序列后两栏均为 `translate(40px,25px)` |
| 灯箱 | 打开后 transform `0,0,1`；滚轮 → `scale(1.15)`；按钮 → `scale(1.38)`；复位 → `0,0,1` |
| 模式隔离 | 灯箱关闭时 `hidden=true / display:none`；切回网格后选中清空、面板收起 |

自动化验收：**180 / 180 断言通过**，`node --check` 与 Sass 编译零错误。

## 9. 可调参数

| 想要 | 改哪里 |
|---|---|
| 对比最大倍率 | `simulation.js` 的 `Math.min(6, ...)`（对比）/ `Math.min(5, ...)`（灯箱） |
| 滚轮步长 | `1.12`（对比）/ `1.15`（灯箱） |
| 对比舞台高度 | `simulation.css` 的 `.sim-compare__stage { height: min(46vh, 380px) }` |
| 窄屏堆叠阈值 | `@container simpage (max-width: 699px)` |
| 关闭对比功能 | 删 `simulation.js` 里的 viewbar 初始化段即可，网格与灯箱保持原样 |
